# Інформаційна система моніторингу стану полів та посівів

Клієнт-серверна система для роботи з даними про поля, спостереження, проблеми та заходи обробки.
Дозволяє переглядати записи, виконувати CRUD-операції через HTTP/JSON, обчислювати інтегральний показник ризику, керувати чотирма станами життєвого циклу проблеми та імпортувати спостереження з CSV у фоновому режимі через JavaFX `Task`.

## Використані технології
* **Java 21** — основна мова програмування серверної та клієнтської частин.
* **Apache Maven** — збірка проєкту, керування залежностями, запуск тестів і JavaFX.
* **JavaFX** — графічний інтерфейс клієнта та фонова задача `Task` з `ProgressBar`.
* **Servlet API 4.0.1** та **Apache Tomcat 9.x** — обробка HTTP-запитів і обмін даними у форматі JSON.
* **JDBC** та **MySQL** — зберігання даних у базі даних.
* **Jackson** — перетворення JSON-даних у Java-об'єкти та назад.
* **JUnit 5** — автоматизовані модульні тести предметної логіки.
* **Git** — контроль версій вихідного коду.
